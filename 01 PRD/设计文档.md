# 诗韵 · 设计文档

古典诗词学习微信小程序（微信小程序原生框架 + 云开发；视觉基准机型 393 × 852，iPhone 15 Pro）。

面向 6–18 岁学生与诗词爱好者，把「读诗 — 学诗 — 朗读 — 默写 — 记录」串成一条完整的学习闭环。

> **版本 v1.1 ｜ 更新 2026-09-15**
>
> **当前范围决策（已确认）**
> 1. **底部导航固定四项**：首页 · 诗词库 · 学习 · 我的（不设「社区」入口）。
> 2. **技术栈**：微信小程序原生框架 + 云开发（`miniprogram/` + `cloudfunctions/`），不再维护 React 原型。
> 3. **暂不实现**：AI 朗读评分（`/result`）、社区互动（`/community`、`/publish`）、诗榜（`/ranking`）。相关章节标注 ⏸ 暂缓，设计保留以备后用。

## 1. 设计定位

| 维度 | 决策 |
| --- | --- |
| 视觉母题 | 水墨山水 + 宣纸质感，克制的现代中式，而非传统「红金喜庆」中国风 |
| 语气 | 安静、鼓励、有书卷气；反馈用诗意短句而非机械文案（如「声情并茂，读得真不错」） |
| 交互性格 | 教育类 App 的清晰层级 + 语言学习类 App 的游戏化正反馈（进度条、按压手感、积分、等级、连续打卡） |
| 反例 | 不用 emoji 图标、不用彩虹色、不用高饱和渐变、不用双 Y 轴图表 |

## 2. 设计语言

### 2.1 色彩

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| 墨蓝 Ink Blue | `#243447` / `#243F4F` / `#2C4B59` / `#304E5B` | 主文字、深色卡片、导航深底 |
| 宣纸白 Rice Paper | `#F8F4EA`（页底）/ `#FFFDF8`（卡片）/ `#ECE7DA`（次级块面） | 亮色页面背景与承载面 |
| 朱砂红 Cinnabar | `#C94A4A`（+ 按压阴影 `#A93C3C`） | 强调、当前态、印章、主行动按钮 |
| 藤黄 Gold | `#C9975A` / `#E8B870` | 等级、勋章、榜单荣誉、进度条暖调 |
| 竹青 Green | `#4F7A5D` / `#5E8A6A` | 正确反馈、「继续学习」CTA、任务完成态 |
| 墨灰文字 | `#7E8785` / `#959B94` / `#A5AAA3` | 次级、辅助、禁用 |
| 深墨绿（学习页） | `#1C2B24` / `#243F4F` / `#1A3330` | 学习页 `LearnHome`、诗词详情 `PoemStudy` 的深色沉浸背景 |
| 暖乳白（覆盖文字） | `#F0E8D8` / `#F5EDE0` | 深色背景上的主体文字 |
| 冷青灰（辅助文字） | `rgba(200,220,210,.5–.85)` | 深色背景上的次级文字、拼音 |

**双色系策略**：应用内存在两套配色语境。

- **宣纸系**（Browse、Home、Profile 等）：`#F8F4EA` 底 + 墨蓝文字 + 朱砂强调。
- **沉浸系**（LearnHome、PoemStudy）：深墨绿底 + `backdrop-filter: blur` 毛玻璃卡片 + 暖乳白文字 + 藤黄金色强调。

原则：同一屏内深色块面不超过一处主体；金色只服务于「荣誉」语义；朱砂只标记「当前 / 主行动 / 错误」。

### 2.2 字体

- `Noto Serif SC` — 诗句、页面标题、数字荣誉值、印章。承担「文气」。
- `Noto Sans SC` — 界面文案、说明、按钮、表单。承担「清晰」。
- 诗句字距放宽至 `.06em–.16em`，行高 1.85，模拟版刻呼吸感；UI 文案 9–13px 紧凑排布。

### 2.3 形状与质感

- 圆角：手机框 43px，大卡片 17–21px，中卡 13–16px，标签/芯片 9–13px。
- 阴影：`0 4px 10px rgba(74,69,51,.05)` 轻卡 → `0 11px 22px rgba(36,52,71,.18)` 深色主卡 → `0 8px 24px rgba(0,0,0,.28)` 沉浸卡。
- `.paper-grain`：全局纸纹叠层（细横纹 + 颗粒点阵，`mix-blend-mode: multiply`，透明度 .44），置于内容之下，赋予宣纸肌理（宣纸系页面使用）。
- **毛玻璃卡片**：沉浸系页面（LearnHome、PoemStudy）的内容块用 `background: rgba(255,252,245,.08–.11)` + `backdrop-filter: blur(16–20px)` + `inset 0 0 0 1px rgba(255,255,255,.13)` 实现，代替宣纸白实底。
- 印章：朱砂方块 / 书签形 `clip-path` 多边形，用于诗题、作品封面。
- 山水元素：`border-radius: 50% 50% 0 0` 的旋转椭圆构成远山，配月晕光环，用于启动页与诗榜头图。

### 2.4 图标 —— 核心规则

> **描边是系统，印章是内容。**

- **描边 SVG** 承担一切系统与操作语义：导航、播放、收藏、评论、搜索、关闭、筛选。统一为 `<Ico name>`：`viewBox 0 0 24 24`、`stroke-width 1.5`、圆头圆角、`stroke: currentColor`。`solid` 属性只对 `play / star / heart / bookmark / sparkle / flame` 生效，用于「已激活」状态。
- **朱砂印章** 只承担内容身份：诗篇、诗人、用户、作品。不用于任何操作按钮。
- **全站零 emoji、零拼凑字符**（v1.2：原「学习分类卡装饰 emoji」的例外已取消，改为描边图标，见 §4.4）。
- 图标库（26 枚）：`back chevron caret arrow close plus / search erase help gear / home book wave person / play pause mic note / heart star bookmark comment share / scroll clock medal sparkle flame brush`。
- 尺寸：`.ico` 默认 `1em`，随上下文字号缩放；仅在按钮几何固定处显式指定像素值。

## 4. 页面设计说明

### 4.1 启动页 `/`
分层水墨场景：云、月（篆字「月」）、三重远山、水纹、芦苇。中央朱砂印章 + 品牌名 + 细分隔线 + 竖排式标语。底部主按钮与一句社区文案。

### 4.2 首页 `/home`
- 深墨蓝「每日一诗」主卡（238px），内含朝代标签、诗题、两句正文、日轮与远山剪影、白底行动按钮。
- 四宫格分类（不同色相圆形字标：唐诗/宋词/元曲/古文）。
- 「继续学习」条：书签形封面 + 进度条 + 剩余提示。
- 热门朗读列表：印章头像、诗题、时长、播放圆钮。**范围变更**：社区暂不做，此列表改为「热门诗词 · 标准朗读」，播放官方音频而非用户作品，去掉作者头像与点赞。

### 4.3 诗词库 `/browse`
三组筛选芯片（学段：小学/初中/高中；体裁：唐诗/宋词/元曲；作者：李白/杜甫/白居易），每组首位「全部」为复位项。

诗词列表卡（`.pc-card`）：左侧正方形配图，右侧诗名（衬线大字）+ 朝代作者行 + 五角星收藏按钮。多选筛选器以 AND 逻辑过滤，无匹配时列表置空。

### 4.4 学习页 `/learn`

沉浸式深墨绿背景，全页毛玻璃卡片风格，与宣纸系形成明确视觉区分。

**顶部进度卡** — SVG 进度环（`stroke-dasharray` 绘制 68% 弧度）显示等级（诗童 Lv5），三列统计（已学诗词 / 已背诵 / 连续天数），藤黄渐变进度条 + 晋级文案，「继续学习」竹青 CTA。

**分类学习** — 2×2 毛玻璃卡格，**四个专项训练分类**（v1.2 调整，去掉原「课本必背 / 考试专项 / 主题学习 / 朗诵练习」）：

| 卡片 | 子分类小字 | 跳转 |
| --- | --- | --- |
| 易错字 | 形近字 · 通假字 · 易混部首 | `/recite?type=word` |
| 易错读音 | 多音字 · 生僻字 · 古音异读 | `/recite?type=pron` |
| 背诵 | 小学必背 · 初中必背 · 高中必背 | `/recite?type=recite` |
| 默写 | 选词填空 · 整篇默写 · 听音写字 | `/recite?type=write` |

四卡共用 `/recite` 页，靠 `type` 参数切换题型与题库，避免四个页面重复实现。装饰图标沿用 §2.4 的**描边图标**（`brush` / `wave` / `book` / `scroll`），保持「描边是系统」的一致性。

**朗读练习入口迁移**：原「朗诵练习」卡取消后，`/practice` 改由 `/poem` 详情页的「我要朗读」按钮进入（见 §4.5），学习页不再直接承载朗读。

**今日任务** — 毛玻璃列表卡，四项任务各带状态切换（点击在「○ 待完成 / ✓ 已完成」间切换），完成项加删除线 + 绿色圆标，标题栏实时显示「n/4 完成」。

**每日推荐** — 竖排诗词卡，左侧 90px 配图，右侧诗名 / 作者朝代 / 推荐理由 / 「开始学习」小徽章，点击进入 `/poem`。

### 4.5 诗词详情 `/poem`（沉浸式重设计）

整页以当前诗词的 Unsplash 配图作为全屏背景（`filter: brightness(.7) saturate(1.1)`，轻度暗化饱和），顶部导航栏叠于图上（透明底 + 文字投影）。

内容区（`study-scroll`）使用独立纸纹叠层和毛玻璃卡片：

- **诗题区**（`.poem-info`）：无卡片底，直接置于背景上，诗名字色 `#F5EDE0`，作者朝代字色 `#C8D8CC`，分隔线改为 `rgba(255,255,255,.2)`。
- **朗读纸**（`.reading-paper`）：毛玻璃卡片（`rgba(255,252,245,.11)` + `backdrop-filter: blur(20px)`）。诗句字色 `#F0E8D8`，拼音字色 `rgba(200,220,210,.7)`。朱丝栏（`.paper-rule`）保留，绝对定位不影响内容居中。左右 padding 完全对称（`24px`）确保 `justify-content:center` 时诗句视觉居中。
- **音乐播放器**（`.mp-player`）：毛玻璃底，进度条填充色改为暖金渐变 `rgba(220,200,160,.9)`，拖动点同色，播放键改为藤黄暖金圆钮（`rgba(220,200,160,.9)`）+ 深绿文字色。倍速下拉菜单背景 `rgba(30,46,40,.88)` + 毛玻璃。
- **译文/注释/赏析**（`.knowledge`）：毛玻璃外壳，分类标签激活色 `#F0E8D8`，正文色 `rgba(230,220,200,.85)`，小圆标背景 `rgba(255,255,255,.12)`。
- **底部操作条**：我要朗读 → `/practice`；背诵默写 → `/recite`；收藏（星标，落库）。

每首诗在 `poems` 集合新增 `img` 字段（云存储 800×400 URL），切换诗词时背景随之变换；进入页面先渲染虚化缩略图占位，大图加载完成后淡入。

### 4.6 朗读练习 `/practice`
录音 + 跟读 + 回放。**不产出 AI 分数、不进入发布流程**（`/result` 已暂缓）。

- 顶部诗句卡 + 标准音频播放（0.75x / 1x / 1.5x 倍速）。
- 中部录音区：波形 + 计时，底部朱砂主按钮「按住/点击录音」，完成后可回放对比。
- 录音存云存储，仅本人可见，可在「我的 → 我的录音」回听。
- 反馈文案仍用诗意短句（如「声情并茂，读得真不错」），不出现分数、排名、发布入口。

### 4.6b AI 朗读评分 `/result` ⏸ 暂缓
92 分评分环 + 光晕轨道装饰，三项指标卡（准确度 / 节奏 / 情感），AI 学习建议卡给出具体到字词的改进点，底部「重新练习 / 发布作品」。**接入第三方语音评测 API 后再启用**，设计保留。

### 4.7 背诵默写 `/recite`
顶部进度条 + 题号，诗句卡填空，选词区 6 枚词条（2 正解 + 4 干扰项），「**问题在眼前，答案在拇指**」版面原则。

**四种题型共用本页**，由 `type` 参数决定：

| `type` | 题型 | 交互 |
| --- | --- | --- |
| `word` | 易错字 | 形近字 / 通假字 / 易混部首四选一，配字源小注解 |
| `pron` | 易错读音 | 多音字 / 生僻字 / 古音异读，选项带拼音，选完朗读该字 |
| `recite` | 背诵 | 逐句遮挡递增（第 n 轮遮住第 n 句），全对进入下一轮 |
| `write` | 默写 | 选词填空（`§4.7` 原设计）；整篇默写与听音写字列入 §8 后续 |

结算页：正确率环（达标竹青 / 未达标藤黄）+ 错题清单（同时给 ✓/✕ 符号与正解，不只用颜色区分）+ 一句诗意反馈。

### 4.8 学习记录 `/progress`
连续天数主卡、指标行、日历热力图、本周学习时长柱状图、最近学习列表。

### 4.9 诗榜 `/ranking` ⏸ 暂缓
水墨夜空头图，三类周榜切换，领奖台 2-1-3，4–10 名列表，底部「我的排名」固定浮条。**依赖社区作品数据，随社区一并暂缓。**

### 4.9b 收藏 `/favorites`
诗词库收藏的诗篇列表，复用 `.pc-card`，空态用降饱和灰占位 + 一句引导文案。

### 4.10 我的 `/profile`
资料头、等级卡（诗童 Lv5 + 晋级进度条）、三格统计、四项线性图标菜单、成就徽章行。

**等级与成就保留**（v1.2 确认）。去掉榜单竞争后，成长感的驱动源改为纯个人数据，与 UGC 完全解耦：

- **等级**：诗童 → 诗士 → 诗仙…… 经验值 = 已学诗词数 + 背诵通过数 × 2 + 连续打卡加成，进度条用藤黄渐变。
- **三格统计**：已学诗词 / 已背诵 / 连续天数（与 `/learn` 顶部进度卡口径一致）。
- **成就徽章**：只保留**学习类与打卡类**，删掉依赖社区的类型（如「获赞 100」「作品上热门」）。首批建议：初出茅庐（学满 1 首）、小有积累（10 首）、过目成诵（背诵 20 首）、持之以恒（连续 7 天）、韦编三绝（连续 30 天）、字斟句酌（易错字全对 10 题）。
- **四项菜单**：学习记录 `/progress`、收藏 `/favorites`、我的录音、设置。

## 5. 图表规范（学习记录 · 本周时长）

- **形式**：竖向柱状图，单序列，不设图例，标题即序列名。
- **颜色**：单一色相 `#3D6172`；今日单独用朱砂 `#C94A4A` 表示「状态」。
- **标记**：柱宽 64%，柱顶 4px 圆角；网格线 1px `#EFEADE`，弱于数据。
- **标签**：只直标今日与悬停项；图下一句结论式注解。
- **不做**：不做双 Y 轴、不做彩虹配色、不做 3D 或渐变柱。

正确率环：单值 `conic-gradient` 环形指示 + 中心大数字，达标竹青 / 未达标藤黄。

| 空/未解锁态 | 降饱和灰（`#DDD9D0` 底、`#AAA69D` 字），保留形状 |

### 6.1 令牌层

`src/index.css` 末尾的「设计系统层」用 CSS 自定义属性收口散落的字面量：

- **墨** `--ink #243447` / `--ink-card #243f4f` / `--ink-soft #2c4b59`
- **宣纸** `--paper` / `--paper-card` / `--paper-sunken`
- **语义** `--cinnabar` `--cinnabar-deep` `--gold` `--gold-light` `--bamboo`
- **墨阶文字** `--ink-2` → `--ink-5`
- **字号阶** 10 / 11 / 12 / 13 / 15 / 17 / 21 / 27 / 38 px，最小字号 **10px**。

### 6.2 无障碍下限

- 图标按钮均带 `aria-label`；播放/暂停的 label 随状态改写。
- 状态不只用颜色区分：对错同时给 ✓/✕ 符号与正解文字。
- 分类切换用 `aria-pressed`。
- **可见键盘焦点**：`:focus-visible` 统一 2px 朱砂环 + 2px 偏移；深色背景区域切换为藤黄环。
- **触控区**：底部导航按钮最小高度 46px，头部圆形按钮统一 30px。
- **`prefers-reduced-motion: reduce`** 下关闭全部动画与过渡。

## 7. 技术实现

- **栈**：微信小程序原生框架（WXML / WXSS / JS）+ 微信云开发（云函数 / 云数据库 / 云存储）。原 React 原型仅作视觉参考，**不作为交付物**。
- **目录**：`miniprogram/pages/<page>/` 每页四件套（`.wxml` `.wxss` `.js` `.json`）；`miniprogram/app.json` 声明页面与 tabBar；设计令牌集中在 `miniprogram/app.wxss`；业务云函数放 `cloudfunctions/`。
- **tabBar**：四项（首页 / 诗词库 / 学习 / 我的）。图标沿用描边 SVG 转 base64 或 `iconPath` 黑白两态 PNG，**不使用 emoji**。选中色朱砂 `#C94A4A`，未选中墨灰 `#7E8785`。
- **字体**：用 `wx.loadFontFace` 加载 Noto Serif SC / Noto Sans SC（基础库 2.16.0+，字体文件需 HTTPS 且配 CORS、加进 `downloadFile` 合法域名）；加载失败回退系统衬线 `"Songti SC", "SimSun", serif`。诗句字距 `.06–.16em`、行高 1.85 的排版参数不变。
- **毛玻璃降级**：`backdrop-filter` 在部分 Android 机型无效，沉浸页需准备降级方案（提高 `rgba(255,252,245,.18)` 底色不透明度 + 保底背景图虚化），保证不可用时仍有足够对比度。
- **状态**：收藏、学习进度、连续天数、录音索引落云数据库；播放、拼音开关、标签切换、任务勾选等纯 UI 状态留在页面 `data`。
- **图片**：诗词配图走云存储 + CDN，不用外链（小程序受 `downloadFile` 合法域名限制）。列表缩略图 160×160，详情页背景 800×400。
- **命名约定**：页面样式以页面前缀开头（`.learn-*`、`.poem-*`、`.rec-*`、`.home-*`），避免全局污染。

## 8. 后续可扩展方向

1. **AI 朗读评分**：接入讯飞 / 百度语音评测 API，启用 §4.6b 的评分环与三指标卡设计，朗读页加「去评分」入口。
2. **社区与诗榜**：作品发布、社区流、三类周榜（§4.9），补齐「分享 — 竞争」闭环；诗榜可先做「学习时长榜」等不依赖 UGC 的榜单。
3. **默写题库化**：整篇默写、乱序连句、听音写字三种题型，复用进度条与评测壳。
4. **学习记录数据化**：日历热力度分级（1–4 档单色阶），接入真实学习数据源。
5. **深色模式**：沉浸系已奠定深色基础，宣纸系页面需从同一色阶重新取值并校验对比度，不直接反色。
6. **音频接入**：当前进度条为模拟计时，接入真实 TTS / 音频 URL 后仅需替换播放逻辑，UI 层不变。
