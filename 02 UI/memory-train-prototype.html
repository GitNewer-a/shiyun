方案说明

1配色改回宣纸系（最高优先）

recite 现存样式用 #F7F5EF / #3F7568 / #C9A45C，是一套自成体系的墨绿叶板。改为全站令牌：背景 --paper、卡片 --paper-card、强调 --cinnabar、正文 --ink。改完从首页点进来不再有「换 App」的观感。

2补一个真正的入口页

现在点「记忆训练」直接掉进答题框，用户不知道能练什么、练到哪了。新增 /pages/memory：顶部掌握概况（环形进度 + 连续天数），中间两张题型卡（各自带进度），下面「继续上次」与「最近练习」。首页与 /learn 的入口都改指这里。

3答题页从「一整张白纸」改成「逐句填空」

现状全文默写是一个 168px 的空 textarea，用户要连续输入 20+ 字且无任何即时反馈，提交后只有一句 toast。改为按句分行的字符格：每行带序号，空格用虚线框表示，填了变实线朱砂框。这是把「默写」从作文题变成填空题，认知负担低一个量级。

4判定结果就地展示

现在判对判错靠 wx.showToast，一闪就没，错误位置在哪完全不知道。改为卡内反馈条 + 错字对照区：正确字变绿、错字朱砂色带波浪下划线并显示「你写成 X」、未答显示「未作答」。这是记忆训练最该有的价值——知道错在哪。

5顶部加进度条

现状没有「练到第几题」的概念，一次只面对一首诗。加 3 / 10 进度条后，训练有了终点感，也便于后续扩展成「10 题一组的复习队列」。这一条依赖产品侧先定「一次练一首还是练一组」。

6去掉装饰性字符

现有 wxml 里有 ✎ 铅笔、◯ 灯泡（还用两个 div 拼出来）、✓ 对勾，都是字符拼贴，违反「全站零 emoji / 描边即系统」铁律。改为描边 SVG 图标。

7全文默写：从「一张白纸」改成「逐句作答」

这是全文默写最核心的改动。现状是 520rpx 高的空 textarea，四个问题：①用户不知道从哪下手，第一笔最难；②整片区域没有行位引导，只能靠背景横线猜；③写完无法定位是第几句；④横线与文字靠 line-height:52rpx 配 padding 硬对齐，换机型/字号必错位。
改为逐句一个输入行，首字作为锚点已给出——这既降低起步门槛，又天然建立「第几句」的结构。第一屏里可以看到第 1 句已填、第 2 句正在输入（朱砂光标）、第 3/4 句是占位下划线。

8保住「整段写」的快路径

逐句作答对新手友好，但熟练用户会觉得被切碎。所以第一屏下方保留「或切到整段默写」：一张带横线的纸，可以一次写完不断行。两种模式共用同一套判定逻辑，只是输入形态不同。不要直接用逐句替换掉整段——那会把老用户的效率打回去。

9判定态：逐字标色

第二屏是全文默写的判定结果。现状只有一个 toast，什么都看不见。改为：整诗逐字铺开，对的字正常墨色、错的字朱砂色 + 波浪下划线、漏的字灰色；上方给百分比环形与「21 / 24 字」；下方「需要订正的 3 个字」按「第几句·第几字 → 你写的/正确的」列出，并区分笔误与漏字。

10为什么错字要用波浪线而不是删除线

删除线会让字「消失」，而记忆训练恰恰需要用户看清自己写了什么。波浪下划线是校对的通用语义，既能标出错误又保留原字形，配合下方「你写的 → 正确的」对照，形成可自纠的闭环。
