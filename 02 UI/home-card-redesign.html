改了什么（以下均已写入代码）

A圆角收敛成两档

今日一诗 42rpx → 44rpx（大卡档），其余全部条卡统一 32rpx。原来四宫格 28、继续学习 32、朗读卡 28 三种混用，收成一套后页面立刻"对齐"了。

A底色改成同纸三层

继续学习从 paper-sunken（凹陷灰）改为 paper-card，与朗读卡同底色。现在层次是：背景纸 #F8F4EA → 卡片纸 #FFFDF8 → 沉底搜索框 #F2EDDF，全部是"纸"的不同明度。

A阴影只留给主角

条卡全部去阴影，改用 0.5px rgba(36,52,71,.06) 极浅描边区分边界。只有今日一诗保留一层 0 10px 26px 柔光投影——它本来就是主角，全页唯一有"浮起感"的元素。

B月亮换成描边装饰

删掉右上角 88rpx 实心金色圆，换成卷轴线稿（#D5E4DC，60% 不透明）。符合「描边是系统」铁律，也让被遮挡的诗句区域完整让出来。

B诗句标点修正

原文渲染出 。。 双句号，因为模板里写死了 。 而数据里已带标点。改图里已修正为单句号，代码需同步改 home.wxml 第 15、16 行。

C朱砂方块换成图标

继续学习左侧那个朱砂小方块原本放的是诗名首字「静」，容易被误读成印章。改成描边书卷图标 + 浅底圆槽，右侧箭头也从实心深色改为浅底，整条卡的"点击感"更轻。

C播放量降噪

1.2万 的朱砂红心是页面第二个红色焦点，和「0%」「今日一诗」抢注意力。改为灰色描边播放图标 + 「次播放」文案，红色只保留给真正的强调项。

D四宫格图标收敛

原来四个图标四种颜色（蓝/棕/绿/紫），与学习页三色图标体系打架。收敛为三个墨蓝 + 一个藤黄，仅「学习计划」保留强调色做区分。
